# Hireloop working agreements

- Use OpenCode with capable free OpenRouter models for project work. Check model availability and pricing before use; if no suitable free model is available, report the limitation instead of silently switching to a paid model or provider.
- Keep the project a modular monolith in a monorepo. Keep domain behavior in its owning module and avoid unnecessary services or abstractions.
- Favor the simplest complete implementation. Preserve validation, authorization, error handling, privacy and accessibility, and optimize performance when measurements or clear requirements justify it.
- Verify each meaningful increment with appropriate tests. Do not start or connect to the user's database without their direction.
- Make periodic, focused commits. Write natural, concise commit messages without conventional-commit prefixes such as `feat:` or `fix:`.
- Keep planning documents in `docs/` and the root product plan local and out of Git tracking. Keep `README.md` and `AGENTS.md` tracked.
- Use the GitHub account `Nishanth1812` for Git and GitHub operations unless the user explicitly requests another account.
